? Help: what the buttons do, and which devices can be host or receiver

Buttons

Create
Makes a new group. People join it from the room list in their Watch Party panel, with the password if you set one. Generate fills in a random password. A group nobody joins disappears after a few minutes.
Add
Puts a person or device into the room, without the password. Someone in another room is moved. As host makes them the one everybody follows; as receiver makes them follow the host. The first one in an empty group always becomes host.
Make host
Hands control to that member. The old host becomes a receiver.
Remove
Takes the member out of the room. People land back in their lobby; devices stop being controlled.
Rename, passwords
Edit the room. A new or removed password only matters for people joining from now on.
Close
Ends the room for everyone in it.
Assign code
Gives a Jellyfin user a 4-digit code for the chat bots. It is shown once. They link with it (Discord: /jwp link; Telegram: /link in a private chat with the bot) by typing their Jellyfin name and the code; after that they can create rooms and add their own devices from the chat. One code works for each platform. New code disconnects all their chat accounts. After 10 wrong tries a code stops working until you assign a new one.

Sync column

In sync
Within a couple of seconds of the host.
Catching up
Being moved to the host's position, or loading / buffering.
Not watching
In the room but not playing anything.
Offline
Lost connection. Kept in the room for 90 seconds in case it comes back.

Who can be host or receiver

ClientHostReceiverHow
Jellyfin in a browser, Jellyfin Desktop / Media Player Yes Yes Shows the Watch Party panel. Joins rooms itself; listed under Not in a room.
Jellyfin Android / iOS app Yes Yes Built on the web client, so it shows the panel too. If its native player is turned on, add it as a Jellyfin device instead.
Official Jellyfin Android TV app Yes Yes No panel. Add it under Jellyfin devices; as receiver it is started and kept in sync by remote control.
Fladder Yes No Doesn't accept remote control, so it can only lead.
Other apps (Swiftfin, Infuse, Kodi, ...) Yes Depends Receiver only if the app accepts remote control. The Can be column in Jellyfin devices tells you for each device.

A device only shows up under Jellyfin devices while its app is open and signed in. Receivers stay within about 2 seconds of the host; browsers are closer.
